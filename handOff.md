# Project Overview

This project includes fully implemented authentication, post management, a dynamic workout system, and a dynamic daily check-in flow.

---

# Authentication

- Fully functional **Login**
- Fully functional **Sign Up**
- Authenticated user is **persisted within the app**
- End-to-end working authentication flow

---

# Post Management

- Create Post
- Get Post
- Get Specific Post (by id)

---

# Workout Tab (Fully Dynamic)

- Exercises for the **current day** are dynamically rendered
- Each exercise includes **dynamic sets information**
- Sets can be **edited**
- Coach Notes are **dynamic**
- Key Cues are **dynamic**
- All workout data updates dynamically based on the current day’s training data

---

# Daily Check-In (Dynamic)

- Daily check-in screen is fully dynamic
- If any abnormality is detected, **training gets updated**
- Sets can also be updated based on check-in results
